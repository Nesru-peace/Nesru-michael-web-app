## Faayiloota Keessa Jiran
1. `index.html` — Fuulawwan 3 (Login/Register, Dashboard/Main Page, Profile/Settings) fi Bottom Navigation.
2. `style.css` — Design ammayyaa (Mobile-First, Responsive).
3. `app.js` — Galmee fayyadamaa (Auth), Barreeffama & Suuraa maxxansuu, fi Supabase wal-qabsiisa.
4. `manifest.json` & `sw.js` — Bilbila irratti akka appitti **"Install / Add to Home Screen"** gochuuf (PWA).
5. `icons/icon.svg` — App icon.
